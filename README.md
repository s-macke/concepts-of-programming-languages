# Concepts of Programming Languages
Master Course: Concepts of Programming Languages - Rosenheim Technical University

<img src="docs/img/go.png" width="10%">

The course "Concepts of Programming Languages" is designed as a master's course. Solid programming skills in at least one language are required, and some experience with other programming languages is assumed. Most exercises and examples use Go (Golang) as a concrete example, complemented by languages such as Haskell and Prolog.
We will look at typical styles and application areas like OOP, FP, Parallel-, Distributed- or Systems Programming, and at how coding agents change the way we write code.

## Goal of the Course

1. Gain knowledge about the concepts of existing programming languages
2. Understand when to use which concept, and when not to
3. Look beyond the horizon and increase your ability to learn new languages
4. Learn how Go differs from other languages conceptually
5. Learn to pick the right language for a given problem

Since Go is a multi-paradigm language, the lecture uses Go to demonstrate many basic concepts and to discuss features which are missing in Go. We go from the concrete to the abstract and not vice versa.

## Semester Work

Each student presents a concept, a programming language with a special concept, a theoretical topic or a topic off the beaten track. The semester work consists of a presentation, a short written paper with code examples, a quiz for the fellow students and peer reviews. All details are on the Learning Campus.
