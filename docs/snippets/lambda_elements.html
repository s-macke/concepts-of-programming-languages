1. Variables

x
  • A variable can itself be a function
  • No data types: no numbers, no booleans

2. Functions

λx.x
  • Here: the identity function
  • Functions have no internal state

3. Applications

(λx.x) a = a
  • Apply the identity function to a, the result is a
  • a can also be a function
  • Parentheses avoid ambiguity
